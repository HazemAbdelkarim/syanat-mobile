## Implementation Notes

### Firestore Document IDs

Documents are generated using the pattern:
```
{category_en_slug}_{subcategory_en_slug}_{sequential_number}
```

Example: `ac_services_maintenance_1`

### Bilingual Support

Each service supports both English and Arabic:
- `service_name_en`: English service name
- `service_name_ar`: Arabic service name
- `category_en` / `category_ar`: Category in both languages
- `subcategory_en` / `subcategory_ar`: Subcategory in both languages

### Pricing

Price field is optional (nullable). Currently, all entries have empty prices in the CSV. These can be updated later via:
1. Firebase Console UI
2. Batch update via script
3. Within the Flutter admin panel

## Database Queries Reference

### Get all categories
```
collection('services').query(field: 'category_en')
```

### Get all subcategories for a category
```
collection('services').where('category_en', '==', 'AC Services')
```

### Get all services in a subcategory
```
collection('services')
  .where('category_en', '==', 'AC Services')
  .where('subcategory_en', '==', 'Maintenance')
```

### Get services with prices
```
collection('services').where('price', '>', 0)
```
